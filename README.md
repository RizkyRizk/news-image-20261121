An entry for [news-image-20261121](https://make.fun/bounty/news-image-20261121) on make.fun: sum up 21 November's world news in one image.

## The image

One dense newspaper front page — "THE WORLD IN ONE DAY", dated Saturday 21 November 2026 — packing **36 real stories** from that day across six continents: a lead story with an illustrated panel, a labelled world map marking where the stories happened, three dense columns of headlines with short standfirsts, and a Markets & Weather strip. Every headline traces to a real report from 21 November 2026.

## How it works

`main.py` (Python 3.13, standard library only, no network) copies the finished image `entry.png` in the repository root, byte for byte, to `/output/entry.png`. Running it twice produces identical bytes.

```
python3 main.py
```
